## 🚀 Proyek Unggulan

### 🌤️ Sky: CotL Height Tool (光遇身高查看工具 · Sky cotl height tool)

**Alat gratis berbasis browser untuk memeriksa tinggi badan karakter di game *Sky: Children of the Light*** — tanpa mengunggah data, semua diproses di browser kamu.

*A free, privacy-first web tool for **Sky: Children of the Light** players to check and simulate their in-game avatar height using the Outfit QR Code.*

| Fitur / Feature | Keterangan / Details |
|---|---|
| 📸 **Upload Screenshot** | Unggah tangkapan layar QR Code Outfit / Drag & drop |
| 🔗 **Paste URL** | Tempel URL hasil scan `https://sky.thatg.co/o=` |
| 📏 **Hasil Akurat** | Tinggi saat ini, tertinggi, terendah + detail JSON |
| 🧪 **Simulator Ramuan Resize** | Simulasi tinggi baru secara acak |
| 🖼️ **Pembuat Gambar Berbagi** | Kustomisasi latar, nama pemain, warna, perataan teks |
| 🌍 **4 Bahasa** | 繁體中文 · English · 日本語 · Bahasa Indonesia |
| 🌙 **Mode Gelap** | Toggle tema sesuai kenyamanan |
| 📖 **Tutorial QR** | Panduan bergambar lengkap + galeri tutorial |
| 🕐 **Riwayat** | Catatan pengukuran tersimpan di browser |
| 🔒 **Privasi** | 100% client-side, tanpa server, tanpa unggahan data |
